# Delete Group in Microsoft Entra ID

## Objective

To delete an existing Microsoft Entra ID group when it is no longer required.

## Business Requirement

Removing obsolete groups helps maintain a clean directory and prevents unnecessary or unintended access through inactive groups.

## Pre-requisites

- Access to the Microsoft Entra admin center.
- Appropriate permissions to delete groups.
- Approved group deletion request.
- Confirmation that the group is no longer required.
- Verify that there are no critical applications, licenses, or resources dependent on the group.

## Steps of the Task

### Step 1: Navigate to Groups

Go to:

Microsoft Entra ID → Groups → All groups
<img width="1908" height="942" alt="All groups" src="https://github.com/user-attachments/assets/06c7532a-8ade-422e-9aac-8d21c58bbc9b" />

### Step 2: Select the Group

Search for and select the group to be deleted.
<img width="1906" height="946" alt="image" src="https://github.com/user-attachments/assets/8fe42582-0383-478a-b1af-70a1fff9ceb4" />

### Step 3: Delete the Group

Select:

Delete

Confirm the deletion when prompted.
<img width="1920" height="539" alt="image" src="https://github.com/user-attachments/assets/78eaa75f-13aa-4b88-b9f7-b19e324bf535" />

### Step 4: Verify

Verify that the group is no longer listed under All groups.
<img width="1910" height="813" alt="image" src="https://github.com/user-attachments/assets/62b0fc70-37e0-480e-a9b7-55fc9745dba7" />

The deleted group may be available under Deleted groups during the applicable recovery period.
