# License Assignment in Microsoft Entra ID

## Objective

To assign the required Microsoft Entra ID/Microsoft 365 licenses to a user based on their role, business requirements, and approved access request.

## Business Requirement

Users require appropriate licenses to access Microsoft services and applications based on their job responsibilities.

License assignment ensures that users receive the required services while maintaining proper access governance and avoiding unnecessary license consumption.

## Pre-requisites

- Access to the Microsoft Entra admin center.
- Appropriate administrative permissions to manage licenses.
- Approved license assignment request.
- User's User Principal Name (UPN) or other unique identifier.
- Required license/SKU is available in the organization's tenant.
- Verify that the selected license is appropriate for the user's business requirement.

## Steps of the Task

### Step 1: Login to Microsoft Entra Admin Center

Navigate to the Microsoft Entra admin center and sign in using an authorized administrator account.

### Step 2: Navigate to Users

Go to:

Microsoft Entra ID → Users → All users

### Step 3: Search for the User

Search for the required user using the User Principal Name (UPN) or another unique identifier.

Verify the user's details before proceeding.

### Step 4: Open the User Account

Select the required user account and open the user's profile.

### Step 5: Navigate to Licenses

Go to:

Licenses → Assignments

Select Add assignments.

### Step 6: Select the Required License

Select the required license based on the approved request.

Review the available service plans included with the license.

### Step 7: Assign the License

Select the required license and click:

Review + assign

Review the assignment details and select Assign.

### Step 8: Verify License Assignment

Return to:

User → Licenses

Verify that the required license is displayed under the user's assigned licenses.

Confirm that the license status is successfully assigned and the required service plans are available.
