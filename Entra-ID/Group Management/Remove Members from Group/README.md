# Remove Members from Group in Microsoft Entra ID

## Objective

To remove users or devices from an existing Microsoft Entra ID group when group-based access is no longer required.

## Business Requirement

Removing unnecessary group membership helps enforce least privilege and ensures users retain only the access required for their role.

## Pre-requisites

- Access to the Microsoft Entra admin center.
- Appropriate group management permissions.
- Approved access removal request.
- Existing group and member identified.

## Steps of the Task

### Step 1: Navigate to Groups

Go to:

Microsoft Entra ID → Groups → All groups

### Step 2: Select the Group

Search for and select the required group.

### Step 3: Navigate to Members

Select:

Members

### Step 4: Select the User

Search for and select the member that needs to be removed.

### Step 5: Remove the Member

Select:

Remove

Confirm the removal when prompted.

### Step 6: Verify

Verify that the user no longer appears in the group's Members list.
