# Microsoft Entra ID - Single Sign-On (SSO)

This repository contains Microsoft Entra ID Single Sign-On (SSO) administration, configuration, and management documentation. It covers the implementation of secure authentication, authorization, and automated identity provisioning for enterprise applications integrated with Microsoft Entra ID.

Microsoft Entra ID SSO enables users to access multiple applications using a single set of credentials, improving user experience, strengthening security, and simplifying identity management across the organization.

---

## SAML SSO

Configuration and management of Security Assertion Markup Language (SAML) based application integrations within Microsoft Entra ID.

### Areas Covered

- SAML Application Onboarding
- Claims Configuration
- Certificate Management
- User Provisioning Integration
- Troubleshooting SAML Authentication

## OAuth / OpenID Connect (OIDC)

Implementation and administration of modern authentication and authorization protocols for applications, APIs, and services.

### Areas Covered

- OAuth 2.0 Configuration
- OIDC Integration
- Token Management
- API Authentication
- Application Permissions
- Delegated Permissions

## SCIM Provisioning

Automated provisioning and lifecycle management of users and groups between Microsoft Entra ID and connected applications.

### Areas Covered

- User Provisioning
- Group Provisioning
- Attribute Mapping
- Lifecycle Automation
- Provisioning Monitoring
- Troubleshooting Synchronization Issues

---

## Benefits of Single Sign-On (SSO)

- Improved user experience through seamless application access
- Reduced password fatigue and helpdesk requests
- Enhanced security using centralized identity management
- Simplified application access governance
- Streamlined onboarding and offboarding processes
- Consistent authentication and authorization across enterprise applications
- Automated user lifecycle management through provisioning integrations
