# Manage Group Owners in Microsoft Entra ID

## Objective

To add or remove group owners in Microsoft Entra ID to ensure appropriate ownership and administration of groups.

## Business Requirement

Group owners are responsible for managing group membership and administration. Maintaining accurate ownership supports access governance and operational accountability.

## Pre-requisites

- Access to the Microsoft Entra admin center.
- Appropriate group management permissions.
- Approved owner change request.
- Existing group.
- New owner identified.

## Steps of the Task

Go to:
