# Configure MFA Registration Campaign

## Objective
Encourage users to register for Multi-Factor Authentication through Microsoft Authenticator.

## Business Requirement
Increase MFA adoption across the organization and improve overall security posture.

## Pre-Requisites
- Microsoft Entra ID tenant
- Microsoft Authenticator enabled
- Authentication Administrator role

## Steps of the Task

1. Sign in to the Microsoft Entra Admin Center.
 <img width="1917" height="961" alt="MS Entra Admin Center" src="https://github.com/user-attachments/assets/7ce22b52-c283-4f41-8a37-79fcb1e5c063" />

2. Navigate to **Protection** → **Authentication Methods**.
 <img width="1920" height="955" alt="Authentication methods" src="https://github.com/user-attachments/assets/7803ee20-26ad-4068-ab07-20616436f5a8" />

3. Select **Registration Campaign**.
 <img width="1903" height="940" alt="image" src="https://github.com/user-attachments/assets/bd1efc80-092a-4ac1-9406-f0689f46bb8a" />

4. Enable the registration campaign.
 <img width="1901" height="231" alt="image" src="https://github.com/user-attachments/assets/f47cc0c9-28fa-439d-a83e-81856a6475f9" />

5. Assign target users or groups.
 <img width="1907" height="945" alt="image" src="https://github.com/user-attachments/assets/ec59aa50-ec7d-449a-a821-ca7f72b05f3c" />

6. Configure campaign frequency.
7. Configure snooze settings.
 <img width="1917" height="418" alt="image" src="https://github.com/user-attachments/assets/9ea7f74d-ab29-4793-b03a-95139ee3cb52" />

8. Save the configuration.
9. Notify users of registration requirements.
10. Monitor MFA registration progress.
