# Create Microsoft 365 Group

## Objective

To create a Microsoft 365 Group for collaboration and shared access to Microsoft 365 resources.

## Business Requirement

Microsoft 365 Groups provide a common membership model for collaboration across services such as Outlook, SharePoint, and Microsoft Teams.

## Pre-requisites

- Access to the Microsoft Entra admin center.
- Appropriate permissions to create Microsoft 365 Groups.
- Approved group creation request.
- Group name and description.
- Group owner identified.
- Group members identified.

## Steps of the Task

### Step 1: Navigate to Groups

Go to:

Microsoft Entra ID → Groups → All groups

### Step 2: Create Group

Select:

New group

### Step 3: Configure Group Details

Select:

- Group type: Microsoft 365
- Group name: Enter the required group name
- Group description: Enter the purpose of the group
- Membership type: Assigned

### Step 4: Configure Privacy

Select the required privacy setting:

- Public
- Private

### Step 5: Add Owner and Members

Select the required group owner and members.

### Step 6: Create the Group

Select Create.

### Step 7: Verify

Verify that the Microsoft 365 Group has been successfully created and that the configured owner and members are present.
