# Add Members to Group in Microsoft Entra ID

## Objective

To add users or devices to an existing Microsoft Entra ID group based on approved access requirements.

## Business Requirement

Adding members to groups provides users with access to resources, applications, licenses, or permissions associated with the group.

## Pre-requisites

- Access to the Microsoft Entra admin center.
- Appropriate group management permissions.
- Approved access request.
- Existing group.
- User or device details to be added.

## Steps of the Task

### Step 1: Navigate to Groups

Go to:

Microsoft Entra ID → Groups → All groups
