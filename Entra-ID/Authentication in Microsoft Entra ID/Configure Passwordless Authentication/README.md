# Configure Passwordless Authentication

## Objective
Enable passwordless authentication methods to improve security and user experience.

## Business Requirement
Passwordless authentication reduces credential theft risks and supports modern identity security strategies.

## Pre-Requisites
- Microsoft Entra ID tenant
- Microsoft Entra ID P1 or P2 license
- Microsoft Authenticator or FIDO2 Security Key enabled
- Authentication Administrator role

## Steps of the Task

1. Sign in to the Microsoft Entra Admin Center.
2. Navigate to **Protection** → **Authentication Methods**.
3. Enable passwordless authentication methods.
4. Configure Microsoft Authenticator Passwordless Sign-In.
5. Configure FIDO2 Security Keys if required.
6. Assign users or groups.
7. Save the settings.
8. Instruct users to register their passwordless credentials.
9. Test passwordless sign-in functionality.
10. Monitor adoption through sign-in logs and reports.
