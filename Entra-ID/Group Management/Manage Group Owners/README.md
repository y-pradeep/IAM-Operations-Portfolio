# Manage Group Owners in Microsoft Entra ID

## Objective

To add or remove group owners in Microsoft Entra ID to ensure appropriate ownership and administration of groups.

## Business Requirement

Group owners are responsible for managing group membership and administration. Maintaining accurate ownership supports access governance and operational accountability.

## Pre-requisites

- Access to the Microsoft Entra admin center.
- Appropriate group management permissions.
- Approved owner change request.
- Existing group.
- New owner identified.

## Steps of the Task

### Step 1: Navigate to Groups

Go to:

Microsoft Entra ID → Groups → All groups

### Step 2: Select the Group

Search for and select the required group.

### Step 3: Navigate to Owners

Select:

Owners

### Step 4: Add an Owner

Select:

Add owners

Search for the required user and select Select.

### Step 5: Remove an Owner

Select the existing owner that needs to be removed and choose:

Remove

### Step 6: Verify

Verify that the required users are listed under the group's Owners section.
